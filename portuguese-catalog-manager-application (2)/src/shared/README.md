# Shared

Componentes e contratos que podem ser usados por mais de uma feature sem conhecer uma feature específica.

Exemplos futuros:

- botões, modal, avatar e estados vazios;
- hooks de foco, teclado e mídia;
- funções de formatação realmente genéricas.

Não coloque regras de pessoas, galeria ou progresso aqui apenas para evitar escolher um domínio. Se algo tiver dono, ele deve morar na feature desse dono.
