# Gamification

Domínio de XP, nível, conquistas, desafios semanais e recompensas visuais.

Recompensas devem reconhecer uma ação real do catálogo. Não usar XP para exigir abertura diária nem para esconder dados funcionais.

A implementação atual está em `src/lib/progress.ts` e a facade em `index.ts` evita que telas importem detalhes internos.
